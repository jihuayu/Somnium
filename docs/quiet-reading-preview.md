# 「浮生纪梦」前端改版与验收

本次在 `codex/quiet-reading-preview` 分支实现，供 Vercel Preview 评审，尚未合并或发布到正式博客。

## 逐项对照

| 文档要求 | 实现 |
| --- | --- |
| 保留名字、标志、内容、评论及首页顺序和分页 | 沿用现有配置、内容接口与分页；归档是独立页面 |
| 静态页眉，左侧标志和站名共同返回首页 | 删除吸顶观察器、标题切换、模糊、缩放、宽度动画和空白区域点击 |
| 右侧只保留关于与搜索；订阅移到页脚 | 页脚另提供“全部文章”，首页保留说明文字，文章不重复 |
| 首页最大文字宽度 680px、手机两侧 20px | 正文、列表、页眉共用布局变量，宽版正文保留 920px |
| 列表标题桌面 19px、手机 18px、字重 500、行高 1.6 | 首页、搜索和标签页共用 `BlogPost`；桌面日期紧随标题，手机置于下一行 |
| 条目间距桌面 28px、手机 24px；页眉间距 56px / 40px | 使用 `rem`，标题完整换行，不添加卡片、逐条分隔线或阅读更多按钮 |
| 摘要仅使用作者提供的说明 | 只展示已有 `summary`；不截取正文生成摘要 |
| 正文 17px、桌面行高 1.85、手机 1.8 | 样式限于博客正文，不修改共享 Notion 渲染包的默认排版 |
| 文章标题 28px / 25px、字重 500、行高 1.4，小标题从 22px 起 | 使用无衬线字体；作者链接指向关于，标签移至文末 |
| 普通与宽版文章并存，代码和宽表局部滚动 | 保留 `wide`、`codeHeavy` 与既有横向滚动容器 |
| 至少四个主要小标题才显示目录，允许人工覆盖 | 以文章最高层级的小标题计数；`tocOverrides` 按 slug 指定；空目录不显示 |
| 宽屏侧栏目录，手机文首折叠目录 | 目录锚定实际正文列边缘，视口不足时使用“目录”折叠入口 |
| 正文结束后保留 48–64px 停顿 | 文末入口间距为 52px；有明确关系时才提供一至两条文字链接 |
| 不强行推荐或总结每篇文章 | 仅为两篇个人软件开发记录配置上下文链接；目标必须已发布，去重并排除自身 |
| 空评论只提示一次，已有评论正常显示，不自动聚焦 | 零评论不显示计数，不展示默认邀请文案；保留一条“还没有评论。”和登录操作 |
| 统一明暗模式的中性色及文字对比度 | 背景与主次文字采用原方案角色，既有界面的 stone 色阶统一为中性灰；正文链接保留下划线 |
| 搜索完整中文化、隐藏底层报错并保留可访问标签 | 页面标题、输入、状态、搜索、清空、重试均使用中文；结果共用文章条目 |
| 搜索与首页视觉一致，手机导航易点 | 输入和按钮有清楚边界与焦点；标签改为可换行文字链接，操作区至少 44px 高 |
| 搜索切换、清空、重试和浏览器返回 | 查询写入网址；切换标签保留关键词，返回或刷新恢复；取消的旧查询不能覆盖新结果 |
| 按年份的完整目录 | `/archive` 按博客时区、年份及日期倒序列出全部文章，并加入页脚和站点地图 |

## 实际验证

- `pnpm test`：155 项测试通过，包括目录阈值和覆盖、时区跨年、关联目标过滤、搜索语义和标签查询保留。
- `pnpm lint`：无错误；保留 `lib/server/notionOgImage.tsx` 原有图片警告。
- `pnpm build`：44 个静态页面生成成功；使用现有只读内容接口构建，不修改生产内容、评论或数据。
- Chrome：320px 浅色、390px 明暗、1440px 明暗五组检查；逐组检查搜索、重试、标签切换、返回、完整目录、正文和评论。
- 样文为《想到了就写，写完就发布》《影评〈世界的主人〉》《RocksDB 上的布谷鸟过滤器》。普通正文 680px、宽版正文 920px，手机两侧 20px；未出现整页横向滚动，代码和表格保留。
- 评论验收在浏览器中替换读取响应，分别覆盖零评论和已有评论；不发送真实评论、登录或账户变更。其他文章内容与搜索查询使用实际预览接口。
- 搜索另外模拟后发请求先返回、旧请求忽略取消后延迟返回，确认当前结果不会被过期数据覆盖。
- 搜索输入与提交在客户端完成初始查询恢复后启用，避免脚本尚未接管时的提前输入被初始化覆盖。
- 用户对版式和阅读体验的最终评审以 Vercel Preview 为准。

## 重跑浏览器验收

机器上需要安装 Google Chrome，以及 Python 的 `playwright` 包：

```sh
python -m pip install playwright
python -X utf8 scripts/verify-reading-preview.py https://nobelium-git-codex-quiet-reading-preview-wwwao102oiws.vercel.app
```

也可以先运行 `pnpm build`、`pnpm exec next start --hostname 127.0.0.1 --port 4137`，再将验收地址替换为 `http://127.0.0.1:4137`。

截图写入已忽略的 `.cache/quiet-reading/`，相同检查重跑时覆盖原文件。浏览器验收会验证所有首页分页的文章与归档一致，不将个人数据或截图提交到 Git。
